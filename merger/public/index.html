⬇️ تحميل
📚 توثيق API للمطورين

واجهة برمجية عامة بدون تسجيل — CORS مفتوح، والأخطاء بصيغة {"error":"..."} بالعربية.

MethodEndpointالوظيفة
POST/api/jobsإنشاء مهمة دمج (روابط و/أو ملفات)
POST/api/upload?job=&seq=&chunk=رفع أجزاء ثنائية ≤ 4MB
POST/api/jobs/<id>/processتنفيذ الدمج كاملًا → رابط الناتج
GET/api/jobs/<id>الحالة + التقدم + الرابط عند الاكتمال
GET/api/jobs/<id>/videoبث الناتج بدعم Range — ?download=1 للتحميل
DELETE/api/jobs/<id>حذف فوري شامل
GET/api/configالحدود العامة + version
GET/api/cronحذف المهام المنتهية (Cron يومي)

حالات المهمة: queued → (uploading) → processing → done | failed

curl -X POST /api/jobs \
  -H "Content-Type: application/json" \
  -d '{"videos":["https://example.com/clip1.mp4","https://example.com/clip2.mp4"]}'
# → 201 {"jobId":"...","status":"queued","statusUrl":"...","processUrl":"...","expiresAt":"..."}
curl -X POST /api/jobs/<jobId>/process
# → 200 {"status":"done","videoUrl":"...","downloadUrl":"...","size":1234567,"duration":30.2,"resolution":"1280x720","expiresAt":"..."}
curl /api/jobs/<jobId>
# → 200 {"jobId":"...","status":"processing","progress":65,"expiresAt":"..."}

الملفات والناتج يُحذفان تلقائيًا بعد 24 ساعة — نزّل الناتج سريعًا.
